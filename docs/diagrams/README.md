# docs/diagrams/

Mermaid source for architecture diagrams. Rendered inline by GitHub and by the
VS Code extension `bierner.markdown-mermaid` (in the recommended extensions).

The primary architecture diagram lives in the root [README](../../README.md) so
it is the first thing seen. Diagrams here are the detailed ones referenced from
milestone docs.

Update a diagram in the same commit as the change it describes. A stale diagram
is worse than none — it is confidently wrong.
