What I'm building

A small self-hosted system that runs my own life admin — a ticket queue, a handful of agents that pick work off it, and a messaging bridge so I can task it from my phone. It is deliberately over-engineered for what it does: segmented networks, a single source of truth for every service, and a written record of every architectural decision including the ones that turned out badly.

The interesting part has not been the agents. It has been everything around them — least privilege for something that executes code it wrote itself, and monitoring that catches silent failure rather than loud failure. Loud failures take care of themselves.
